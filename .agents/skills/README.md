# RevForge Codex Skills

Copy the six folders in this archive to your project root under:

```text
.agents/skills/
```

The final structure should be:

```text
.agents/skills/
├── revforge-mercurial-protocol/SKILL.md
├── revforge-backend/SKILL.md
├── revforge-frontend/SKILL.md
├── revforge-security/SKILL.md
├── revforge-quality/SKILL.md
└── revforge-operations/SKILL.md
```

Each skill contains specialized operating rules for Codex while building RevForge.
